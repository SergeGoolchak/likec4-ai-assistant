# Диагностика проблем

<a id="confluence-pat"></a>
## Personal Access Token не подходит

Токен создаётся в профиле пользователя Confluence (обычно раздел "Personal Access Tokens" в настройках профиля). Убедитесь, что:

- токену не выставлен срок действия в прошлом;
- у пользователя, создавшего токен, есть доступ на чтение к пространству, где лежит нужная страница;
- адрес сервера указан без завершающего слэша и с правильной схемой (`http://` для внутренних тестовых стендов, `https://` для реальных серверов).

<a id="ai-base-url"></a>
## AI-провайдер не подключается

Если поле адреса сервера пустое — используется настоящий `api.openai.com`, и тогда API-ключ обязателен. Если указан адрес локального/self-hosted сервера — проверьте, что:

- сервер уже запущен и слушает указанный порт (например `http://localhost:11434/v1` для Ollama);
- адрес указан с суффиксом `/v1`, если сервер того требует (большинство реализаций протокола OpenAI Chat Completions используют этот префикс);
- если сервер всё же проверяет Authorization-заголовок — заполните поле ключа, даже если это "локальный" сервер.

## "Файлы изменились на диске с начала анализа"

Это сообщение Apply означает, что кто-то (или что-то) отредактировал один из затрагиваемых файлов уже после того, как начался анализ, — Apply намеренно не перезаписывает такие файлы молча. Запустите новую задачу заново на актуальном состоянии репозитория.

## Сессия зависла на "паузе", хотя я уже всё решил

Проверьте, не осталось ли открытых вопросов на экране Анализа — pipeline не продолжится, пока не отвечено абсолютно на все. Если вопросов нет, но статус всё равно "на паузе" на стадии Apply — это ожидаемо: Apply — гейт, требующий явного нажатия кнопки, а не автоматической стадии.
