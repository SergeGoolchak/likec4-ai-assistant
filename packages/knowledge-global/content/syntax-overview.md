# Обзор синтаксиса LikeC4

LikeC4-проект состоит из `.c4`/`.likec4` файлов с тремя верхнеуровневыми блоками, которые могут быть разнесены по разным файлам одного проекта:

```
specification {
  // объявление допустимых типов элементов и связей
}

model {
  // сами элементы архитектуры и связи между ними
}

views {
  // представления (диаграммы), построенные из модели
}
```

Идентификаторы элементов (`fqn`, fully qualified name) уникальны в пределах проекта и формируются вложенностью через точку: `paymentsPlatform.orderService`. При добавлении нового элемента внутрь существующего родителя достаточно объявить его в теле родителя — не нужно повторять полный путь.

Комментарии — `//` до конца строки. Строки (title, description) — в двойных кавычках; многострочные описания можно оформлять как markdown-блок.
